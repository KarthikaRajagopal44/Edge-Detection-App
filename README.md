# Edge-Detection-App

A simple and interactive **Streamlit** application that allows users to perform **Canny Edge Detection** on images with real-time adjustable thresholds.

### Install dependencies to run this
```bash
pip install streamlit opencv-python-headless pillow numpy
```

### To run the code
```bash
streamlit run canny-edge-app.py
```

## 🛠 Features
* **Image Upload:** Supports JPG, JPEG, and PNG.
* **Real-time Processing:** Use sliders to adjust Lower and Higher thresholds for the Canny algorithm.
* **Instant Feedback:** View the original and processed images side-by-side.
